# 🌐 Purpleguy Hybrid Browser

Chrome'un hızı, Brave'in gizliliği ve Opera GX'in oyuncu odaklı kontrol mekanizmalarının **Purpleguy** ruhuyla birleşimi. 

> **Slogan:** "Built with Tablet Power, Driven by Innovation."

## ✨ Özellikler
- **💜 Purpleguy UI:** Neon mor detaylar ve tamamen siyah (OLED dostu) arayüz.
- **⚡ GX Control:** RAM ve CPU kullanımını görsel olarak sınırlayın.
- **🛡️ Brave Shields:** Reklam ve takipçilere karşı simüle edilmiş koruma.
- **👤 Hacker Mode:** Tek tıkla gizlilik ve özel tema geçişi.
- **🚀 Splash Screen:** Havalı bir açılış animasyonu.

## 🛠️ Kurulum
1. Bu repoyu klonlayın: `git clone https://github.com/aftonpurpleguy560-byte/Purple-Hybrid-Browser.git`
2. `index.html` dosyasını tarayıcıda açın veya Electron.js ile paketleyin.

## 📱 Platform Desteği
Bu proje özellikle **tablet üzerinden** geliştirilmiş ve optimize edilmiştir.
